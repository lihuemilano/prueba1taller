machine learning: fifa

Usa frames captados de partidos reales

EA combina dos cosas:

- Captura de movimiento real

- Machine Learning + redes neuronales

Se grabaron partidos completos de fútbol profesional utilizando trajes Xsens, obteniendo millones de fotogramas de movimiento.

Esos datos sirven para entrenar modelos de ML.

Así, el modelo puede generar diferentes movimientos en tiempo real dependiendo de lo que esté ocurriendo.
